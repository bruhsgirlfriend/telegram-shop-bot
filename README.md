# Telegram Shop & Order Management Bot

Готовое решение Telegram-бота для интернет-магазина, локального бизнеса или службы доставки на стеке **Python 3.11+ / aiogram 3.x / SQLite**.

## 🌟 Возможности

- **Интерактивный каталог товаров**: список товаров, подробные карточки с ценами, описанием и кнопками добавления.
- **Полноценная корзина покупателя**: расчет суммы заказа, поштучный подсчет, возможность очистки или дозаказа.
- **Оформление заказа (FSM)**: сбор контактных данных клиента (ввод номера или отправка в 1 клик через `request_contact`).
- **Мгновенные уведомления администратору**: детальный состав корзины, контакты заказчика и ссылка на профиль сразу приходят в чат владельца.
- **Асинхронная база данных**: безопасно и быстро благодаря `aiosqlite`.
- **Автоматический seed демо-товаров**: готов к запуску сразу после клонирования.

---

## 🛠 Стек технологий

- **Язык**: Python 3.10+
- **Фреймворк**: [aiogram 3.15+](https://github.com/aiogram/aiogram) (современный асинхронный фреймворк)
- **Конфигурация**: `pydantic-settings`
- **База данных**: SQLite через `aiosqlite`

## 🚀 Быстрый запуск

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/your-username/telegram-shop-bot.git
cd telegram-shop-bot
python -m venv .venv
source .venv/bin/activate  # Для Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настройка окружения
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```
Укажите ваши параметры:
```env
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
ADMIN_ID=987654321
DATABASE_PATH=shop.db
```
*(Токен бота получается у [@BotFather](https://t.me/BotFather), а ваш числовой ID можно узнать через [@userinfobot](https://t.me/userinfobot)).*

### 3. Запуск бота
```bash
python main.py
```
